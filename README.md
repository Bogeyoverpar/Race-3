# LRA Racing Simulator UI

Local Streamlit UI for the event-driven race simulator.

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
streamlit run app.py
```

If needed:
```bash
python -m streamlit run app.py
```

Edit `data/drivers.csv` and `data/schedule.csv` in Excel to tinker with ratings and races.
